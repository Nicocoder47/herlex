## 📝 Descripción

Herlex es el sitio institucional de un estudio jurídico boutique liderado por mujeres, enfocado en brindar asesoría legal con perspectiva de género, empatía y estética profesional.

El proyecto simula un estudio real con secciones informativas, testimonios, contacto y servicios legales. Fue desarrollado como proyecto final del curso, aplicando HTML, SASS, Bootstrap y GitHub Pages.

---

## 🛠️ Herramientas y Tecnologías

- HTML5 semántico
- SASS (SCSS modular)
- CSS3
- Bootstrap 5
- Font Awesome
- AOS.js (Animaciones on Scroll)
- Git y GitHub
- GitHub Pages
